# 影之刃零存档管理器

本项目由 AI 生成。它不是《影之刃零》（Phantom Blade Zero）的官方工具，与游戏的开发商、发行商没有关系，也没有得到授权。

存档有问题时，先回档，再考虑改数值。程序不修改游戏本体，也不往游戏进程里注入任何东西。

## 能做什么

- 从 Steam 库找到游戏目录，以及当前存档 `ProjectPBZ\Saved\SaveGames\Steam\<账号>\PBZSaveGame.sav`。
- 列出游戏自己留下的三组备份：真实时间（`1RealTime`）、按小时（`2Hourly`）、按天（`3Daily`）。
- 窗口开着时，大约每两秒看一次这些目录。新备份出现后会补进当前列表，不用重开窗口，也不会清掉正在看的内容和已经选中的槽位。
- 把这些备份再复制一份到管理器自己的目录。复制不会写回游戏目录。游戏以后清掉旧备份，这里仍然可以拿来回档。
- 整份回档，或只把某一份备份里的一个槽覆盖到当前存档的同名槽。
- 查看槽位里的关卡、存档内时间、游戏时长、存档点、尘埃、剩余天数、武器，以及任务的完成情况和分支里的子任务进度。
- 在先做安全备份的前提下，修改角色槽的尘埃、剩余天数，或修改全局数据里的继续槽。

任务内容只读。管理器不会改任务进度。已经完成的分支，不再把清零后的计数当成进度。

## 打开

当前发行版是 v0.1，在仓库的 Releases 里下载 `PBZSaveManager.exe`，双击打开。从源码打包时，程序在 `dist\PBZSaveManager.exe`。

窗口会按屏幕大小和系统缩放调整。拉大或缩小后，说明、当前存档路径、备份列表和任务文字会跟着换行。

窗口上方有两个功能按钮：

- **回档**：按真实时间、按小时、按天，或查看管理器留存。
- **查看和修改**：看当前存档，或做上面说的那几项修改。

游戏是否在运行，会用颜色标在路径下面：

- 橙色：游戏正在运行。这时不能回档，也不能修改。
- 绿色：游戏已退出到桌面，可以回档或修改。
- 灰色：暂时确认不了。写入会暂停。

源码调试可以在项目目录执行：

```powershell
$env:PYTHONPATH = "src"
python run.py
```

## 回档

1. 先退出游戏，回到桌面。
2. 打开「回档」。
3. 选择真实时间、按小时、按天，或管理器留存。
4. 在列表里点一份备份。需要看槽位目录时，点「读取所选内容」。
5. 确认是想要的进度后，点「回档到所选」。

回档会替换整个当前存档。写入之前，当前的 `PBZSaveGame.sav` 会先复制到安全备份。

没有角色进度槽的备份不能用来回档。只含高级数据、不能改槽的备份，仍然可以整份回档。

「重新检测」会重新找游戏和当前存档。「手动选择存档」可以指定另一份 `PBZSaveGame.sav`。

## 查看和修改

打开「查看和修改」。

左边是当前存档的槽位。点一个槽，可以看目录；点「读取所选槽的内容」后，才能看到任务、尘埃和剩余天数。

可以写回去的只有这三项：

- 角色槽的尘埃
- 角色槽的剩余天数
- 全局数据里的继续槽

写入前同样会先做安全备份。写完会再读出来核对。核对失败就不会替换当前存档。

「覆盖当前同名槽」用来把某一份备份里的一个槽，拷进当前存档的同名槽。其余槽保持原样。自动存档和手动存档可以互拷。成就和全局数据不会拿去覆盖角色进度。

## 程序自己的文件

这些文件在 `%LOCALAPPDATA%\PBZSaveManager`，不在游戏目录里。

- `mirror`：从游戏备份额外留的一份。
- `safety`：每次真正写入当前存档之前留下的整份备份。
- `manager.log`：操作记录。
- `config.json`：手动选择存档后记住的路径。

界面上可以打开存档目录、留存目录和安全备份目录。

## 图标

窗口和程序图标使用本机已安装游戏的图标，并在右下角加了一个白色的 E。

图标从本机游戏程序提取，仓库里不附带图标文件。需要图标时，在项目目录执行：

```powershell
$env:PYTHONPATH = "src"
python tools\make_icon.py
```

打包时 `build.ps1` 会自己调用这一步。

## 从源码打包

需要 Python 3.11 或更高版本。在项目目录执行：

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

脚本会安装依赖、运行测试、生成 `dist\PBZSaveManager.exe`，并关掉打包器默认带上的控制流保护。这个标记不关掉的话，读取槽位时程序会被系统结束。

## 使用时注意

- 游戏进程 `PBZ.exe` 还在运行时，管理器拒绝回档和修改。
- 管理器不改游戏的 `1RealTime`、`2Hourly`、`3Daily`，也不改游戏程序。
- 如果开了 Steam 云存档，回档后进游戏时要确认读到的是这份进度。云存档可能把本地改动盖回去。
- 数值修改只处理尘埃、剩余天数和继续槽。其他进度不对时，用回档。
